# Irogra Server Manager (Irogra SM)

**Minecraft Java Edition向けのWindows用サーバー管理アプリケーションです。**

Irogra Server Manager（Irogra SM）は、Minecraftサーバーの構築・起動・停止・管理を、GUIから簡単に行うことを目的として開発されたソフトウェアです。

WindowsのネイティブUIを採用し、サーバー管理に必要な機能を一つのアプリにまとめています。

## 主な機能

- Minecraft Java Editionサーバーの作成・起動・停止
- 複数サーバーの管理
- サーバー設定・ワールド管理
- Mod・プラグイン・データパックの検索・導入・管理
- Modrinthからのファイル取得
- 対応バージョン・Modローダーの互換性チェック
- インストール済みファイルの更新・削除
- Javaのインストール・管理
- Minecraft Java EditionのVanillaクライアント起動機能 (デバッグ機能)
などなど。

## 対応OS

| 対応OS | UI |
|---|---|
| Windows 10 / 11 | WinUI 3 |
| Windows 7 | WPF |

Windows 10 / 11版では、AcrylicやMicaを活用したWindowsネイティブデザインを採用しています。

Windows 7版はレガシー環境向けに提供しています。

配布形式：
- **Setup.exe** — インストーラー版
- **Portable.zip** — インストール不要のポータブル版

**各バージョンはGitHub Releasesからダウンロードできます。**
※Windows 7版はポータブル版のみの配布です。

使用しているWindowsのバージョンに合ったリリースを選択してください。

## 注意事項

- 本ソフトウェアは非公式のMinecraft関連ツールです。
- Mojang StudiosおよびMicrosoftの公式製品ではありません。
- サーバーやModの構成によっては、正常に動作しない場合があります。
- 重要なサーバーデータは定期的にバックアップしてください。
- Windows 7はMicrosoftのサポートが終了しているため、利用時にはセキュリティ上のリスクに注意してください。
- Windows 7版のアップデートは不定期に行います。
- Build 11.0以前のビルドは配布しておりません。
